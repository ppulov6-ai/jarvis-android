# Джарвис для Android

Открытая разработка голосового помощника на русском языке на основе [ClawDroid](https://github.com/KarakuriAgent/clawdroid).

## Текущее состояние

Встроенный вариант ARM64 использует OpenAI Responses API. В настройках достаточно ввести API-ключ и нажать «Подключить»: приложение проверяет ключ, выбирает gpt-5.4-mini и официальный адрес API автоматически. Подписка ChatGPT не оплачивает API.

Интерфейс и распознавание речи работают на русском языке. Перемещаемый космо-шарик отражает состояния прослушивания, обработки и озвучки. Нажатие раскрывает управление, удержание останавливает помощника. Обычные окна Android перекрываются; системные экраны и уведомления подчиняются ограничениям Android.

Добавлены локальное подтверждение действий, отмена задач с отсечением запоздавших команд и шифрование ключей через Android Keystore. GitHub Actions проверяет тесты и собирает APK. Работа на телефоне и голос проверяются отдельно; универсальная фильтрация чувствительных экранов не заявляется.

## Согласованные требования

1. Samsung Galaxy S25, Android 16, One UI 8.5. Совместимость проверяется на устройстве.
2. Интерфейс и сообщения на русском языке, локальный русский мужской голос.
3. OpenAI API для понимания команды и планирования, приложение выполняет действия на телефоне.
4. Открытие, поиск, чтение и подготовка текста без дополнительных подтверждений.
5. Отправка сообщений, публикации, звонки, удаление, передача файлов и важные настройки после подтверждения конкретного действия.
6. Банковские операции и ввод секретов выполняет пользователь.
7. Кнопка «Стоп», проверка результата и защита от повторного выполнения.
8. Минимальный контекст для модели, защита чувствительных полей, ключи через Android Keystore.

## Проверка сборки

GitHub Actions собирает встроенный Go backend и отладочный APK ARM64 без производственных ключей подписи. APK появляется в артефактах и предварительном выпуске с прямой ссылкой после успешной сборки. Перед использованием на телефоне отдельно проверяются подтверждение, отказ, «Стоп» во время ожидания и действия, перезапуск с сохранением ключа, а также отсутствие ключей в конфигурационных файлах. «Стоп» прекращает дальнейшие действия, но не отменяет уже отправленное сообщение или выполненное изменение.

Разрешение на снимки экрана, нажатия, жесты и ввод текста запрашивается один раз и сохраняется до отзыва в разделе «Разрешения». Неопределённые команды, intent и broadcast требуют подтверждения с параметрами. Серверные команды оболочки, самостоятельная отправка сообщений, MCP и запись файлов отключены в защищённом Android режиме, чтобы не обходить подтверждение приложения. Чтение файлов ограничено отдельной рабочей папкой, включая защиту от перехода через символические ссылки. Чтение дерева интерфейса исключает парольные поля; ввод в парольное поле заблокирован. Android не помечает все чувствительные данные одинаково, поэтому универсальная защита банковских экранов пока не заявляется.

Локально: `make build-android-arm64`, затем `cd android && ./gradlew :app:assembleEmbeddedDebug`.

## Испытание на телефоне

Если Android запрещает включение службы: Настройки → Приложения → Джарвис → ⋮ → Разрешить ограниченные настройки. После этого вернитесь в специальные возможности и включите службу. Приложение не снимает системное ограничение автоматически. Раздел «Разрешения» показывает состояние службы, микрофона и плавающего окна.

Снимки обычных экранов приложения разрешены. При показе открытого API-ключа снимки блокируются до его скрытия. Окно подтверждения допускает снимки и после закрытия возвращает в предыдущее приложение.

После теста: Настройки → Выгрузить тестовый файл → Сохранить ZIP или Поделиться. Диагностика содержит версию приложения, модель телефона, состояние разрешений и последние 200 технических событий, включая коды ошибок подключения и результаты инструментов. Не включает ключи, переписку, снимки экрана и пользовательские файлы. События сохраняются между перезапусками в отдельном приватном журнале. Добавьте описание шагов и обычный скриншот ошибки при отправке архива на анализ.

Палитра текущей версии основана на предоставленном логотипе ремонтного бота: тёмно-зелёные поверхности, оранжевые акценты, молочный текст.

## Локальные команды 0.4.3

«Найди контакт Мама», «позвони Мама», «набери +79990001122», «найди контакт Мама и позвони» и «сделай скриншот» обрабатываются на телефоне до отправки в OpenAI. Это работает в текстовом чате, голосовом режиме и плавающем шарике. При нескольких контактах или номерах назовите номер варианта; выбор действует две минуты и сбрасывается кнопкой «Стоп». Неоднозначный контакт не выбирается автоматически.

Команда набора открывает системную звонилку с номером; сам звонок запускается её кнопкой. Снимок сохраняется в галерею Pictures/Jarvisjon и не передаётся модели. Явно прикреплённые изображения в основном чате остаются в пути анализа. Отказ в разрешении и ошибки локальной команды не переключают её на модель. Для поиска указывайте имя как в телефонной книге; угадывание имени и падежов не выполняется.

API-ключ и соединение с внутренним сервером сохраняются. Периодические фоновые обращения к модели выключены в Android runtime. Запросы в чате, анализ и явно настроенные задачи агента используют модель. Распознавание голоса выполняет системная служба Android, её доступ к сети зависит от настроек телефона. Диагностика включает только категории local_contacts, local_dial, local_screenshot без имён, номеров и изображений.
