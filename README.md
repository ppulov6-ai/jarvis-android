# Джарвис для Android

Открытая разработка голосового помощника на русском языке на основе [ClawDroid](https://github.com/KarakuriAgent/clawdroid).

## Текущее состояние

Перенесены исходники ClawDroid, настроена сборка встроенного варианта для ARM64. Это техническая основа, а не готовая первая версия Джарвиса. Русские ресурсы интерфейса добавлены; распознавание речи настроено на ru-RU, озвучка использует только локальные русские голоса. Добавлены локальное подтверждение действий, отмена задач с отсечением запоздавших команд и шифрование ключей через Android Keystore. Тесты и сборку проверяет GitHub Actions; работа на телефоне ещё не проверена. Полная фильтрация чувствительного контекста требует отдельной проверки. Мужской голос выбирается и проверяется на устройстве. Не подключайте реальные аккаунты и ключи к промежуточной сборке.

## Согласованные требования

1. Samsung Galaxy S25, Android 16, One UI 8.5. Совместимость проверяется на устройстве.
2. Интерфейс и сообщения на русском языке, локальный русский мужской голос.
3. OpenAI API для понимания команды и планирования, приложение выполняет действия на телефоне.
4. Открытие, поиск, чтение и подготовка текста без дополнительных подтверждений.
5. Отправка сообщений, публикации, звонки, удаление, передача файлов и важные настройки после подтверждения конкретного действия.
6. Банковские операции и ввод секретов выполняет пользователь.
7. Кнопка «Стоп», проверка результата и защита от повторного выполнения.
8. Минимальный контекст для модели, защита чувствительных полей, ключи через Android Keystore.

## Проверка сборки

GitHub Actions собирает встроенный Go backend и отладочный APK ARM64 без производственных ключей подписи. APK появляется в артефактах только после успешной сборки. Перед использованием на телефоне отдельно проверяются подтверждение, отказ, «Стоп» во время ожидания и действия, перезапуск с сохранением ключа, а также отсутствие ключей в конфигурационных файлах. «Стоп» прекращает дальнейшие действия, но не отменяет уже отправленное сообщение или выполненное изменение.

Неопределённые команды, нажатия, ввод, снимки экрана, intent и broadcast требуют разового подтверждения с параметрами. Чтение дерева интерфейса исключает парольные поля; ввод в парольное поле заблокирован. Android не помечает все чувствительные данные одинаково, поэтому универсальная защита банковских экранов пока не заявляется.

Локально: `make build-android-arm64`, затем `cd android && ./gradlew :app:assembleEmbeddedDebug`.
